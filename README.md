# :3 Doodle Jump

A fan-made vertical jumper starring the :3 cat. Climb 1,000 m to the Moon,
grab the 100B MC flag, then walk on the Moon.

Bounce on platforms, grab fish, ride rockets — and don't fall.

## Play

Open `index.html` in a browser — the game is a single self-contained file
(all artwork is embedded, no build step, no server needed).

Or play it on GitHub Pages once enabled for this repo:
Settings → Pages → deploy from the `main` branch.

## How it works

- Climb as high as you can — the market cap rises with altitude.
- Platforms: normal, moving, breakable, springs, rockets.
- Cracked platforms bounce once, then break and fall away.
- Fish pickups along the way.
- Moon = 1,000 m / 100B MC — land on the Moon and the game is won.
- On the Moon: WALK ON THE MOON — the cat walks left-right and does
  little happy hops, with a meow every third hop.
- Two original WebAudio music tracks: a cheerful chiptune climb (132 BPM)
  and a dreamy moon lullaby (92 BPM) at the finish. 🔊/🔇 toggle
  bottom-right; music starts on PLAY.
- Rocket overshoot? No problem — the camera follows you back down to the
  Moon, no cheap fall death above Moon level.

## Controls

- Drag / ← → / A D — steer (wraps left-right)
- Automatic bouncing — just steer and don't fall
- Touch works on mobile
